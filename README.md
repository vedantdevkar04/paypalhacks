# HiClose

Every "hi" under your post is a customer. HiClose answers every one of them in their language,
knows which product they mean, and closes the sale in the DM, with payments by PayPal.

This is our entry for the PayPal AI Hackathon. The project is in progress; setup steps are in
[CLAUDE.md](CLAUDE.md).
